TAESAN DAILY V4 手机编辑版

包含从你备份恢复的 2026 年 9 月 41 条营业记录。

【升级】
1. iPhone Safari 登录 GitHub，打开原 TAESAN DAILY 仓库。
2. 将本文件夹内 index.html 和 data.json 上传/替换到仓库根目录。
3. 注意：如果你此前已在 GitHub 公开 data.json 中添加过其他正式记录，请先合并，勿直接覆盖！
4. 等 GitHub Pages 发布后刷新网站。
5. 点击“管理”→在“数据备份与发布”按月份/关键词查找→点击“编辑”→修改→保存。
6. 每次编辑后先“导出 data.json”，再上传替换 GitHub 的 data.json 才能公开发布。

【安全】
V4 仍是纯静态网站，没有管理员登录或云数据库。任何人都能打开管理界面并修改自己的本地副本，但无法借此修改你的 GitHub 仓库。不要把密码或密钥写进 index.html。

【迁移】
V4 沿用 V3 的浏览器本地数据键 taesan-daily-v3；同时随包附带你的 datav3.json 作为网站初始 data.json。
