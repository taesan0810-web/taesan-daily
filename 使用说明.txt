TAESAN DAILY V3 · 使用说明

1. 在 GitHub 仓库 taesanonly 的 Code 页面，把 index.html、data.json 上传到根目录并覆盖旧版同名文件，提交 Commit changes。
2. GitHub Pages 部署完成后，刷新网站（手机可能需要关闭旧页面再打开）。
3. 录入：网站点击「录入管理」，填写公开营业条目或每日 DM 数量。支持同日同平台多条记录。
4. 发布：点击「导出 data.json」，将下载的新 data.json 上传到仓库根目录并覆盖旧文件。GitHub Pages 部署完成后所有访客可见。
5. 安全：任何访客都能看到「录入管理」，但访客在自己浏览器中的录入不会自动改变公开数据。不要将它误认为受密码保护的后台。公开 DM 仅存统计数字。
6. 旧版 V2 的 data.json 数组结构可被网站读取，但 V3 导出的数据是对象结构。旧版浏览器本地记录不会自动迁移，请先在旧网站导出 data.json，再在新版的管理页面导入。
7. 照片：可以填写公开可访问的 HTTPS 图片 URL，或者把获授权图片上传至仓库 assets 文件夹后填写 assets/图片名.jpg。避免上传付费 DM 内容。
8. 网站没有预填真实营业记录，避免把未核实的微博截图条目或示意数字当成事实。请按实际链接逐条录入。
9. 本版暂未实现真正的后台登录、自动图片水印、云端同步或一键年报图片导出。
