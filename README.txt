TAESAN DAILY

1. 本地预览：在此文件夹运行 python -m http.server 8000，然后访问 http://localhost:8000
2. 公开上线：将 index.html 和 data.json 上传到 GitHub 仓库，使用 GitHub Pages 发布（Settings > Pages）。
3. 录入：打开网站 > 管理记录 > 填写并保存 > 导出 data.json。
4. 更新公开内容：用导出的 data.json 替换仓库中的 data.json，等待网站部署完成。
注意：本机记录只保存在当前浏览器，不会自动同步给访客。不要把管理功能当作有密码保护的后台。

升级：支持平台分类、歌曲/舞台/重要瞬间、官方链接、年度及月份统计。年报数字来自实际录入记录。
